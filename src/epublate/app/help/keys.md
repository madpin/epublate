# Keyboard reference

The **Keys** tab below this one introspects the active screen's
bindings live; this Markdown reference gives you the global picture
plus the cross-screen shortcuts that don't fit the per-screen list.

## Global

| Key      | Action                                           |
|----------|--------------------------------------------------|
| `?`, F1  | Open this help modal                             |
| `T`      | Cycle theme (textual-dark → textual-light → epublate-contrast) |
| `Ctrl+C` | Quit                                             |

## Projects screen

| Key | Action |
|-----|--------|
| `n` | New project |
| `o` | Open existing project |
| `Enter` | Open selected recent project |
| `?` | Help |

## Dashboard

| Key | Action |
|-----|--------|
| `o` | Open Reader |
| `g` | Open Glossary (lore bible) |
| `i` | Open Inbox |
| `b` | Run a Batch translation |
| `e` | Run intake (helper-LLM proper-noun pass) |
| `x` | Save / export ePub |
| `B` | Set / clear budget cap |
| `s` | Open Settings |
| `r` | Refresh stats |
| `q` | Back to Projects |

## Reader

| Key | Action |
|-----|--------|
| `↑`/`↓`, `j`/`k` | Move segment cursor |
| `←`/`→`, `h`/`l` | Move chapter cursor |
| `t` | Translate the highlighted segment |
| `b` | Translate the entire current chapter |
| `a` | Approve translation |
| `f` | Flag translation |
| `q` | Back |

## Glossary

| Key | Action |
|-----|--------|
| `n` | New entry |
| `Enter` | Edit entry |
| `l` | Toggle lock status |
| `c` | Cascade re-translation for the highlighted entry |
| `d` | Delete entry |
| `q` | Back |

## Inbox

| Key | Action |
|-----|--------|
| `Enter` | Open the flagged segment in the Reader |
| `r` | Re-translate from the Inbox |
| `q` | Back |

## Settings

| Key | Action |
|-----|--------|
| `e` | Edit style guide |
| `a` | Toggle auto tone-sniff |
| `Tab` | Switch panel |
| `q` | Back |
